# Settings

In Settings, you can configure app settings, including:

- **Language**
- **Network** (Mainnet or Preprod)

## Where to Find Settings

- **Desktop:** in the top navigation bar, next to the wallet button.
- **Mobile:** inside the sidebar menu.

## Change Language

1. Open **Settings**.
2. Go to **Language**.
3. Select your preferred language.
4. Confirm the interface text updates correctly.

## Change Network

1. Open **Settings**.
2. Go to **Network**.
3. Select **Mainnet** or **Preprod**.
4. The app redirects you to the website for the selected network (Mainnet or Preprod).
5. Reconnect your wallet if prompted after the redirect.

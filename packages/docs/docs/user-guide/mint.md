# Mint

This page explains how to mint assets in Open Djed.

You can mint:

- **DJED**
- **SHEN**

## Requirements

- Wallet connected
- Sufficient ADA balance for the mint amount and fees

## Step-by-Step

1. Open the **Dashboard** page.
2. Select action **Mint**.
3. Select asset **DJED** or **SHEN**.
4. Enter the amount of tokens you want to receive(Mint).
5. Review estimated output and fees.
6. Click **Mint** button, then a popup will appear to confirm the transaction in your wallet extension.
7. Wait for on-chain confirmation.

## Verify Result

- A new order appears in **Orders** with the latest status.

# Orders

The Orders page helps you track mint and burn operations from creation to completion.

## What You Can Do

- View pending and completed orders
- Inspect order details and status
- Cancel eligible pending orders

## Typical Order Lifecycle

1. **Created**: transaction created, waiting for on-chain processing.
2. **Completed**: operation finished successfully.
3. **Cancelled**: operation was not finalized.

## Step-by-Step

1. Open the **Orders** page.
2. Filter by status if needed.
3. Open order details to inspect more information.
4. If available, click **Cancel** for eligible pending orders.
5. Confirm cancellation in your wallet.

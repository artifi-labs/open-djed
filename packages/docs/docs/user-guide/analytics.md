# Analytics

The **Analytics** page explains how to use analytics charts and the SHEN yield simulator.

On this page, you can inspect:

- Historical charts
- Current DJED/SHEN metrics
- Trend changes over time
- Price behavior across available markets

## Step-by-Step

1. Open the **Analytics** page.
2. Select the chart or metric you want to analyze.
3. Adjust the timeframe to compare short-term and long-term trends.

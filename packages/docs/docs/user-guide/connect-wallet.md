# Connect Wallet

This guide explains how to connect your Cardano wallet to Open Djed.

## Before You Start

- Install a supported Cardano wallet extension (for example, Eternl or Lace)
- Open the Open Djed app on the correct network (Mainnet or Preprod)

:::warning Network Must Match
Wallet connection only works when your wallet network matches the website network.
If they do not match, the app shows an error and blocks the connection.
:::

## Step-by-Step

1. Click **Connect Wallet** in the top navigation.
2. Select your wallet provider from the list.
3. Approve the connection request in your wallet extension.
4. Wait for the app to show your wallet.

## What to Check After Connecting

- Make sure you didn't encounter any errors during connection.

## Troubleshooting

- If the wallet is not listed, confirm the extension is installed and enabled.
- If connection is rejected, retry and approve in the extension popup.
- If you get a network mismatch error, switch either the wallet network or the website network so both match, then reconnect.

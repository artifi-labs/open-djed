# Burn

This page explains how to burn assets in Open Djed.

You can burn:

- **DJED**
- **SHEN**

## Requirements

- Wallet connected
- Asset balance available (DJED or SHEN)
- ADA available for transaction/network fees

## Step-by-Step

1. Open the **Dashboard** page.
2. Select action **Burn**.
3. Select asset **DJED** or **SHEN**.
4. Enter the amount of tokens you want to pay(Burn).
5. Review estimated output and fees.
6. Click **Burn** button, then a popup will appear to confirm the transaction in your wallet extension.
7. Wait for on-chain confirmation.

## Verify Result

- A new order appears in **Orders** with the latest status.

# FAQ

**What is Open Djed?**  
Open Djed is an open-source alternative interface layer that allows users to interact with the original Djed protocol developed by COTI and IOG.

**Does Open Djed create a separate stablecoin protocol?**  
No. Open Djed is an alternative way to access the existing Djed protocol.

**Which networks are supported?**  
Mainnet and Preprod.

### Wallet & Connection

**Which wallets are supported?**  
We currently support the following wallets:

- Eternl
- Lace
- Yoroi
- Begin
- Gerowallet
- Vespr

**My wallet does not connect. What should I do?**  
Make sure your wallet extension is installed and unlocked, then refresh the page and reconnect.

### Transactions & Orders

**My transaction is pending for a long time.**  
Transactions may appear pending because our system updates order states periodically. The script checks for new orders and updates their status at regular intervals, so please wait a short while and check again.

**Can I cancel an order?**  
Yes, if the order is still eligible for cancellation. Use the Orders page and follow the cancellation flow.

### Analytics & Data

**How often is analytics data updated?**  
Most analytics use historical data that is updated once per day. This daily update cycle may cause values to appear outdated compared to the current on-chain state.

**Are analytics values real-time?**  
Analytics are generally based on daily updated historical data and may not be real-time. However, some metrics provide up-to-date values.

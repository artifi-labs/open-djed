Copy and fill this template:

```md

- Network: Mainnet / Preprod
- Wallet: (Eternl, Lace, etc.)
- Browser + version:
- Device: Desktop / Mobile

### What Happened

- Action performed: (mint, burn, cancel order, etc.)
- Expected result:
- Actual result:
- Error message (exact text):

### Useful References

- Transaction hash (if available):
- Order ID (if available):
- Screenshot/video:
- Timestamp (UTC):
```

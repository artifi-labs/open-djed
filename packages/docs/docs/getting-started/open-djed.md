# Open Djed

Open Djed is an open-source project designed to provide a transparent, reliable, and community-driven way to interact with the Djed stablecoin ecosystem. It empowers users, developers, and organizations to access and integrate Djed functionalities with greater flexibility and independence.

Rather than introducing a new stablecoin protocol, Open Djed serves as an alternative interface and interaction layer for the existing Djed protocol developed by COTI and IOG. Its purpose is to enable seamless interaction with Djed **without depending on the original COTI application and infrastructure**.

## Why Open Djed?

The motivation behind Open Djed comes from several limitations and issues observed with the official COTI Djed application, including:

- Frequent application failures and bugs.
- Accessibility problems in certain regions.
- Lack of recent updates and improvements.
- Limited transparency and flexibility for integration.

By offering an open, community-driven alternative, Open Djed aims to:

- Provide a more reliable and accessible way to interact with the Djed protocol.
- Enable independent audits, improvements, and integrations.
- Foster innovation and collaboration within the Cardano and DeFi communities.

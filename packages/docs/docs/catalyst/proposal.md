# Catalyst Proposal: Building Open Djed
- **Proposal Link:** [Project Catalyst Proposal](https://milestones.projectcatalyst.io/projects/1400095/)

Open Djed submitted a **development and maintenance proposal to Project Catalyst** on **Nov 24, 2025**.

This proposal focused on one core objective: ensure that Open Djed remains a reliable, community-driven interface for interacting with the Djed protocol through continuous development, maintenance, and infrastructure support.

## Proposal Goals

The Catalyst proposal requested support to:

- Maintain and stabilize the platform with continuous technical work
- Deliver new features based on user and ecosystem needs
- Improve reliability, observability, and operational readiness
- Expand accessibility through internationalization
- Strengthen documentation and developer-facing tooling

## Why Catalyst Was Critical

Catalyst funding was essential to move from a basic working product to a sustainable platform with long-term support.

With Catalyst support, the team could:

- Allocate dedicated time for maintenance and iterative releases
- Build and ship higher-value features with predictable cadence
- Scale backend/data workflows needed for analytics and orders

## Catalyst-Enabled Outcomes

The proposal support translated into concrete product and engineering outcomes:

- **Feature delivery:** analytics improvements, SHEN yield simulator anbd order management
- **Accessibility:** multilingual support (i18n) for broader community reach
- **Infrastructure maturity:** stronger production readiness and monitoring
- **Developer enablement:** documentation and tooling improvements for easier contributions and onboarding

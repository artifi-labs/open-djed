# Milestone 2 - SHEN Yield Simulation & Maintenance

- **Submitted:** January 24, 2026 at 12:00 PM UTC
- **Milestone Cost:** 7.50% (ADA 7,500)
- **Milestone Link:** [Milestone 2](https://milestones.projectcatalyst.io/projects/1400095/milestones/2)

---

## Milestone Outputs
The milestone delivers all necessary code and deployment changes to enable:

- SHEN yield simulation and tracking functionality  
- Maintenance of **Open DJED** and user support for the 2nd month after proposal start


## Acceptance Criteria
To consider this milestone completed:

- The views for SHEN yield simulation and tracking are consistent with the visual profile of the Open DJED app  
- Users can access a page for simulating and tracking SHEN yield over time  
- For the second month after proposal start:  
  - Public up-time dashboard shows ≥ 99% availability  
  - Minimal service interruptions occur  
  - GitHub issues tagged as "bug" are triaged within 48 hours and resolved in subsequent releases  
  - User support channels on the Artifi community Discord are actively monitored, with response times under 24 hours for critical inquiries


## Evidence of Completion
Completion is evidenced by:

- A link to the SHEN yield simulation page  
- Screenshots or video walkthrough demonstrating the new functionality  
- Links to main GitHub pull requests introducing the features and implemented source code files  
- Public up-time monitoring dashboard: [https://status.artifi.finance/](https://status.artifi.finance/)  
- GitHub repository showing bugfix pull requests and resolved issues: [https://github.com/artifi-labs/open-djed](https://github.com/artifi-labs/open-djed)  
- Screenshots or links to public discussions on Discord/GitHub

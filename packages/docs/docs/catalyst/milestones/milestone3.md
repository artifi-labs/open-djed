# Milestone 3 - DJED Analytics Dashboard & Maintenance

- **Submitted:** April 1, 2026 at 2:39 PM UTC
- **Milestone Cost:** 17.50% (ADA 17,500)
- **Milestone Link:** [Milestone 3](https://milestones.projectcatalyst.io/projects/1400095/milestones/3)

---

## Milestone Outputs

The milestone delivers all necessary code and deployment changes to enable:

- A dedicated publicly accessible **DJED analytics dashboard** section on the Open DJED app
- Inclusion of key DJED metrics (KPIs and other relevant data) visualized via charts, graphs, and other interactive components
- New backend API endpoints to serve aggregated data to the dashboard and third parties
- Maintenance of **Open DJED** and user support for the 3rd month after proposal start

## Acceptance Criteria

To consider this milestone completed:

- The dashboard is live and publicly accessible
- The dashboard includes important key metrics inspired by Ethena and adapted to the DJED model, including but not limited to:
  - Circulating Supply (DJED and SHEN)
  - Reserve Ratio
  - DJED Price on Protocol vs. Secondary Markets (AMM DEXs)
  - SHEN Yield & Total Fees Accrued
  - SHEN/DJED market cap
  - Protocol Volume DJED/SHEN (Breakdown of Minting, Burning, Total per token type)
- Data presented is accurate and updates in a timely manner
- User interface is intuitive and easy to understand
- For the 3rd month after proposal start:
  - Public up-time dashboard shows ≥ 99% availability
  - Minimal service interruptions occur
  - GitHub issues tagged as "bug" are triaged within 48 hours and resolved in subsequent releases
  - User support channels on the Artifi community Discord are actively monitored, with response times under 24 hours for critical inquiries
